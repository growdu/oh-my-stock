# oh-my-stock 使用指南

> 基于实际页面截图式描述。所有内容对应 `main` 分支当前实现。

## 1. 系统是什么

oh-my-stock 是一个**用规则筛股票**的个人系统。

- **数据**：每天自动从新浪/东财/akshare 拉全 A 股最新日线和资金流，计算 MA / MACD / KDJ / RSI / BOLL 指标
- **规则**：16 条内置预设 + 任意多条自定义规则，每条规则用 JSON 描述"满足什么条件算命中"
- **展示**：命中结果直接展示当前 MA/KDJ/RSI/BOLL 数值和形态，点击任意股票弹出 K 线图

**核心心智模型**：选一条规则 → 看命中了哪几只 → 每只命中时点的技术形态是什么 → 点击看 K 线验证。

#### 切换规则

- 鼠标点击左右箭头 ←/→
- 鼠标**滚轮**上下滚（在规则卡区滚）
- 手指**左右滑动**（移动端）
- 直接点击下方 dot 跳转

选中后右侧自动加载命中结果，最多预加载 8 条规则。

#### 命中股票卡片

每张卡包含：

| 区域 | 内容 |
|---|---|
| 顶部 | 代码 / 名称 / 板型 chip（主板-沪市 / 主板-深市 / 创业板 / 科创板 / 北交所） / 排名 #N |
| 行业行 | 当前股票所属申万行业（无则不显示） |
| 左侧价格区 | 当前价（24px）+ 涨跌幅带箭头 + 涨跌额 |
| 右侧指标网格 | 开盘/最高/最低/振幅/换手/PE/PB/净流入(万)/成交量/MACD柱 |
| 底部技术指标条 | MA5/10/20/60 + KDJ + RSI6 + BOLL%b 共 7 个 chip |

#### 技术指标条的颜色含义

| chip | 绿色 | 红色 | 灰色 | 附加标签 |
|---|---|---|---|---|
| MA5/10/20/60 | 收盘 < MA（下方） | 收盘 ≥ MA（上方） | 无数据 | MA5 还可能带「金叉」或「死叉」红字标 |
| KDJ | K < D | K ≥ D | 无数据 | 若 K 上穿 D 且差距≥0.5 → 金叉红标 |
| RSI6 | ≤30 超卖（绿）/ 中性（默认） | ≥80 超买（红） | 无数据 | — |
| BOLL%b | <50% 偏下轨 | ≥50% 偏上轨 | 无数据 | ≤0 触下轨 / ≥1 破上轨 |

#### 行业筛选

命中结果区下方若出现行业 chip 条，点击任一行业只显示该行业的股票；点「全部」清空过滤。chip 上的数字是该行业在当前结果里的命中数。

#### 导出 CSV

右上角「⬇ 导出 CSV」按钮导出当前**已过滤**的命中列表（应用了行业筛选后），列：代码 / 名称 / 板型 / 现价 / 涨跌幅 / 涨跌额 / 振幅 / 换手 / PE / PB / 净流入(万)。

## 3. 创建自定义规则

### 3.1 通过可视化编辑器（推荐）

进入 `/admin/rules` → 「新增规则」 → 填名称 → 在可视化编辑器里：

1. **先选板型**（默认已勾选主板 / 创业板 / 科创板）
2. **点 + 添加条件**，选算子类型，按提示填参数
3. 右侧实时显示生成的 JSON
4. 「保存」入库

支持的可视化算子（按出现频率）：

| 算子 | 何时用 |
|---|---|
| 涨跌幅区间 | 限定涨幅范围，如 -3% ~ 3% |
| 换手率区间 | 限定活跃度 |
| 量比（最小/最大/区间） | 放量 / 缩量 |
| 板型 | 限定主板 / 创业板 / 科创板 / 北交所 |
| 行业 | 仅看某些行业 |
| 连续阳线 / 阴线 | N 天连续收阳/阴 |
| 均线多头排列 | MA5 > MA10 > MA20 > MA60 |
| MA 关系 | MA5 相对 MA10 是 > 还是 < |
| 收盘 vs MA | 收盘在 MA5/10/20 上方还是下方 |
| KDJ 金叉 / 死叉 | KDJ 在零轴上方/下方/任意位置交叉 |
| 排除 ST | 排除带 ST 的股票 |
| 排除创业板 / 科创板 | 单独使用 |

更复杂的算子（如 `bias`、`macd_histogram`、`boll_pct_b`）可在高级 JSON 模式直接编辑。

### 3.2 直接写 JSON（高级）

弹窗底部有「高级模式」展开，可直接编辑 JSON。结构：

```jsonc
{
  "all": [                     // AND 关系，必须全部满足
    { "type": "yang_streak", "days": 3 },                              // 连续 3 天阳线
    { "type": "volume_ratio", "min": 1.5 },                            // 量比 >= 1.5
    { "type": "close_vs_ma", "ma": "ma20", "op": "gt" }                // 收盘 > MA20
  ],
  "any": [                     // OR 关系（可选）
    { "type": "kdj_cross", "location": "below_zero" },                  // KDJ 低位金叉
    { "type": "rsi_range", "min": 20, "max": 30 }                        // 或 RSI 超卖
  ],
  "exclude": [                 // NOT 关系（可选）
    { "type": "is_st" }                                                  // 排除 ST
  ]
}
```

完整算子列表见 [README.md §规则表达式语法](../README.md#规则表达式语法)。

### 3.3 规则的执行

- 在 `/admin/rules` 卡片上点「▶ 执行」立即跑，结果写库 + 下方展示
- 后端接口：`POST /api/v1/user/rules/:id/run`（JWT）

## 4. 数据什么时候刷新

- 默认每天 16:00 由 `timer.py` 触发 `daily_refresh.sh`，17:00 单独跑一次 `refresh_mv.py` 兜底
- 拉取完成后，下次访问 `/` 就能看到新一天的数据
- 想立刻刷新：在服务器上跑 `./scripts/daily_refresh.sh`（不带参数跳过 basic_info）

## 5. 常见问题

**Q: 为什么某条规则命中 0 只？**
A: 该规则的条件组合很严格，或当天行情不符合。建议先放宽一个条件试试。

**Q: 命中股票卡片上 MA5 旁边没显示金叉/死叉标？**
A: 需要同时满足：① 昨值（ma5_prev）和今值（ma5）都存在；② 今值穿越 MA10。缺少昨值时只显示 MA 数字。

**Q: 为什么 K 线图有时没数据？**
A: 通常是因为 `fetch_daily.py` 还没跑过，或某只股票新上市拉不到 60 日历史。直接重跑 `./scripts/daily_refresh.sh --skip-compute` 即可（只重拉不重算）。

**Q: 我加的自定义规则为什么没保存？**
A: 名称或表达式任一为空都会拒绝。JSON 格式错误也会被后端 400。

**Q: 后端报 JWT 过期怎么办？**
A: `/admin/login` 重新登录即可，token 默认 168 小时（7 天）有效。

## 6. 进阶：跑通全流程的命令

```bash
# 1) 启动数据库（任意方式）
psql ... -f scripts/create_table.sql
psql ... -f scripts/refresh_mv.sql

# 2) 启动后端
cd backend && go run .

# 3) 启动前端
cd front && npm run dev

# 4) 首次初始化数据（含基础信息）
cd scripts && ./daily_refresh.sh --initial

# 5) 之后每天会自动跑（如果启动了 timer.py）
IMMEDIATE_RUN=0 python timer.py
```
